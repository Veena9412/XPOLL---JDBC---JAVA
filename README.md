# XPOLL---JDBC---JAVA
XPOLL is a Java project built to practice JDBC (Java Database Connectivity) concepts through a polling application. It demonstrates how to connect Java applications with relational databases, execute queries, and manage persistent data. The project helps learners strengthen SQL integration, exception handling, and modular design in real-world scenarios.
Features:
1. Create, read, update, and delete poll questions and responses
2. JDBC-based database connectivity and query execution
3. Input validation and error handling
4. Structured DAO (Data Access Object) layer for clean design
5. Unit testing for database operations
